Components
==========

.. das:module:: weasel_components

.. das:class:: Area3D

   Jolt sensor (trigger) to detect bodies entering/exiting

.. das:class:: Audio

   Provides audio playback functionality for the entity.

.. das:class:: Character Body

   Capsule-based kinematic character controller (Jolt)

.. das:class:: Directional Light

   Emits parallel light rays in a single direction, like sunlight. 

.. das:class:: Hierarchy

   Defines parent/child relationships between entities

.. das:class:: Model Instance

   Renders a 3D model using the current transform

.. das:class:: Point Light

   Emits light equally in all directions from the entity position, 

.. das:class:: Prefab Instance

   Tracks the source prefab for this entity

.. das:class:: Spot Light

   Emits light in a cone shape from the entity position. 

.. das:class:: Transform

   Controls local position, rotation and scale relative to parent
