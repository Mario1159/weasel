# Roadmap

## Version 1.0 — Foundation

A toy engine by default, but flexible enough to support more complex projects by extending it with custom components.

### Goals
- Establish a solid core architecture
- Enable rapid experimentation and iteration
- Provide essential systems required for basic projects

### TODO
- C++ JIT Compiler Integration (Proteus)
- Event Handling Interface
- Continuous Integration
- Windows Support
- SDL Audio System
- Shadow Mapping

---

## Version 2.0 — Indie-Ready

A usable game engine suitable for new indie projects, focusing on content creation, performance, and distribution.

### Goals
- Support real-world game development workflows
- Improve asset handling and runtime performance
- Enable shipping playable builds

### TODO
- Animation System (Ozz)
- NavMesh Creation & Pathfinding (Recast)
- Physics-based Spatial Audio System (Steam Audio)
- Project Export to Binary/Install
- Texture Mipmapping
- Low-Level Networking (SNS)

---

## Version 3.0 — Maturity

A more mature and stable game engine with expanded platform support and higher-level systems.

### Goals
- Improve scalability and maintainability
- Support larger and more complex projects
- Reduce boilerplate for common gameplay features

### TODO
- Terrain Creation
- Mac Support
- High-Level Networking

---

## Version 4.0 — Experimental & Advanced

Advanced and experimental features aimed at tooling, testing, and cutting-edge rendering techniques.

### Goals
- Improve developer productivity and confidence
- Explore advanced rendering and validation workflows
- Push the engine beyond conventional use cases
